# KittyNutri PWA – GitHub Pages Setup

Dein persönlicher Kawaii Pink Glassmorphism Makro-, Ballaststoff-, Supplement- & 4-Phasen-Zyklustracker.

## Features
- **4 Pink / Rosa Glassmorphism Themes:** Strawberry Milk, Sakura Blossom, Y2K Hot Berry & Velvet Rose Dark
- **Angepasste Makroziele (1,71 m, 77 kg, Gym):** Umschaltbar zwischen *Body Recomp (2.250 kcal)*, *Sanfter Cut (1.900 kcal)* und *Lean Bulk (2.550 kcal)* + automatischer Luteal-Puffer (+150 kcal)
- **4-Phasen Zyklustracker:** Menstruation, Follikelphase, Ovulation & Lutealphase inkl. Perioden-Logger, Symptom-Check-in, Gym-Tipp und phasenspezifischen Lebensmittelvorschlägen
- **Ihr Supplement Stack:** ESN Vitamin D3/K2, Doppelherz Haar Intensiv + Biotin und Doppelherz Reizdarm inkl. kombinierter Mikronährstoff- & Beauty-/Bauch-Bilanz
- **1-Klick Mahlzeiten & Open Food Facts Barcode-Scanner**

## Deployment auf GitHub Pages
1. Neues Public-Repository auf [github.com/new](https://github.com/new) erstellen (z. B. `kittynutri`).
2. Alle entpackten Dateien (`index.html`, `manifest.json`, `sw.js`, `icon.svg`, `icon-192.png`, `icon-512.png`) ins Hauptverzeichnis (`root`) hochladen.
3. Unter **Settings -> Pages** den Branch `main` und `/ (root)` speichern.
4. URL am Smartphone öffnen und über **„Zum Startbildschirm hinzufügen“** installieren.
